# 🚀 SmartStudy AI Flashcard Quiz Generator

An AI-powered Flashcard Quiz Generator designed to help students create interactive study materials and improve their learning experience.

## 📌 Project Overview

SmartStudy AI Flashcard Quiz Generator uses Generative AI to generate flashcards and quizzes from study content. It helps students make revision easier, faster, and more engaging.

## ✨ Features

* Generate AI-based flashcards
* Create quiz questions from study material
* Interactive learning experience
* User-friendly interface

## 🛠️ Technologies Used

* Python
* Streamlit
* Generative AI
* Prompt Engineering

## 🎯 Objective

The main objective of this project is to explore how Artificial Intelligence can be used to create smart learning tools and improve student productivity.

## 🚀 Future Enhancements

* Add more AI models
* Save user learning history
* Improve quiz evaluation system
